# Governance

RhoeMarkdown is maintained by the RhoePlatform founders and invited maintainers.
The project follows a founder-led open-source model: contributors are welcomed,
but public API, language-surface, release, and repository-boundary decisions
remain maintainer decisions.

## Contribution Flow

1. Open an issue for material API, language, or release-surface changes.
2. Keep pull requests focused and aligned with the public compiler package scope.
3. Run the maintainer gates in `README.md` before requesting review.
4. Expect maintainers to prioritize correctness, release hygiene, and platform consistency over rapid surface expansion.

## Decision Boundaries

- The public compiler package lives here.
- SwiftUI preview apps, design-kit utilities, and premium studio apps are separate lanes.
- Public release tags, Homebrew publication, and repository visibility changes require maintainer approval.

## Code Of Conduct

Participation is governed by `CODE_OF_CONDUCT.md`.
