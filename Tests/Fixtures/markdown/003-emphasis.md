# Emphasis Tests

## Basic Emphasis

This is *italic* text using asterisks.
This is _italic_ text using underscores.

This is **bold** text using asterisks.
This is __bold__ text using underscores.

This is ***bold italic*** using three asterisks.
This is ___bold italic___ using three underscores.

## Nested Emphasis

**Bold with *nested italic* inside**
*Italic with **nested bold** inside*

**Bold with _different markers_ for italic**
__Bold with *different markers* for italic__

## Complex Cases

**Bold *italic* and more bold**
*Italic **bold** and more italic*

A**not bold**B (no spaces)
A*not italic*B (no spaces)

## Edge Cases

****Four asterisks****
***Three asterisks***
**Two asterisks**
*One asterisk*

Escaped \*asterisks\* should not be emphasized.
Escaped \_underscores\_ should not be emphasized.
