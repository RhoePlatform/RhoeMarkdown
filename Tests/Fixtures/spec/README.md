# Spec Fixture Corpus

This directory contains the curated conformance corpus for the canonical
`RhoeMarkdown v1` specification.

Rules for fixtures in this folder:

- Keep inputs small and intentional.
- Each fixture should trace back to one or more normative spec sections.
- Prefer one fixture per behavior cluster over giant mixed decks.
- If a fixture captures a known divergence, that divergence should be called out
  explicitly in the conformance matrix.

Current layout:

- `core/`
- `slides/`
- `grid/`
